# `@oss-error-registry/core`

Detector contracts, validation, and the bounded deterministic matching engine
for OSS Error Registry.

The supported public API is the package root export. It includes `analyze()`,
detector/plugin definition helpers, analysis limits and errors, and their
TypeScript types. Internal modules are not exported as package subpaths.

See the [repository README](../../README.md) and
[detector contract](../../docs/detector-contract.md) for project-level usage and
design details.
